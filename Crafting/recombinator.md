# POE2 Recombinator Strategy (High-End / Expert)

Recombinators are the primary tool for creating "Best-in-Slot" (BiS) gear by merging Tier 1 modifiers from disparate bases. Success in v0.4 depends on **Modifier Weighting** and **Base Preservation**.

## 1. THE WEIGHTING META
Every modifier has a "weight." T1 mods (e.g., Flat Phys) have extreme low weights (~25), while garbage mods (e.g., Flat Fire) have high weights (~1200).

- **Modifier Doubling**: If *both* input items have the same mod (e.g., T1 Strength on both), the probability of that mod appearing on the output item is significantly increased.
- **Expert Strategy**: Never attempt to recombine a low-weight T1 mod against a high-weight junk mod. Use **Chaos Orbs** or **Annuls** to clear high-weight junk before merging.

## 2. BASE PRESERVATION
- **Implicit Match**: Always use the same base type (e.g., two "Temporalis Silk Robes") to guarantee the output base.
- **Fractured Synergy**: Merging a fractured item with a non-fractured item is the safest way to "carry" a T1 mod into a multi-modded BiS item.

## 3. EXPERT CRAFTING LOOP (BiS Weapons)
1.  **Item A**: Fracture T1 Flat Physical Damage.
2.  **Item B**: Roll T1 Physical % Damage + T1 Attack Speed.
3.  **The Merge**: Use a Recombinator. If it fails, you lose the base but keep the Fractured Item A for a second attempt.
4.  **Estimated Cost**: 50-100 Divine Orbs per attempt (including base costs).

## 4. SUCCESS PROBABILITIES
| Setup | Success Rate (Desired Mod) | Expert Tip |
| :--- | :--- | :--- |
| **Doubled Mod (Both items)** | ~70-80% | Mandatory for T1 mods. |
| **Single Mod (One item)** | ~35-40% | Too risky for low-weight mods. |
| **Fractured Transfer** | ~100% (Fracture stays) | Use to lock the hardest mod first. |
