# POE2 High-End Map Preparation (Elite Setup)

Expert-level tools for bypassing Atlas progression obstacles and setting up "Full Juice" farming environments.

## 1. THE GRAND PROJECT (Grand Design Tablet)
The ultimate tool for Atlas manipulation.

| Feature | Effect | Expert Strategy |
| :--- | :--- | :--- |
| **Irradiation** | Irradiates all maps in a large radius. | Use to reveal high-density T15 clusters without clearing adjacent beacons/tethers. |
| **Bypass** | Grants access to *all* maps in range regardless of completion. | Use to "jump" into elite layouts (e.g., Willow/Hive). |
| **Juice Scaling** | Enhances the difficulty and reward floor. | Mandatory for permanent T15 regions. |

## 2. BOSS PROGRESSION (v0.4+ Splinter Tiers)
Pinnacle boss access has been unified. "Audience with the King" and similar keys are removed.

- **The Splinter Loop**: Breach, Ritual, Expedition, and Simulacrum now use a 300-splinter sequence (50/100/150).
- **Expert Strategy**: Do not spend splinters on T1/T2 unless you are ready to immediately push the T3 (150 splinters) for the elite drops.
